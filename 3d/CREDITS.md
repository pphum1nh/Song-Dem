## Nhân vật: Vocations and Uniforms (Free)
- Nguồn: itch.io (gói "Vocations-and-Uniforms-Free").
- **Tác giả: cần bổ sung tên theo trang itch.io của gói.** File README trong gói không ghi tên.
- Giấy phép: Creative Commons Attribution-ShareAlike (CC BY-SA).
- Trong game: `assets/chars/*.json` (glTF nhúng sẵn dữ liệu), xuất từ file `.blend` gốc bằng Blender 5.3. Đã nén lưới, đổi texture sang WebP. Tư thế và dáng đi được tạo trong code (`character.js`).
